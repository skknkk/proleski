# Рабочий каталог C:\ai — проект «Проклятый лес»

Главная инструкция координатору. Следующие файлы подгружаются в каждый диалог и обязательны к исполнению:

@cursed-forest/status/rules.md
@cursed-forest/status/context.md
@cursed-forest/docs/project_map.md

Чек-лист `status/checklist.md` и словарь `docs/glossary.md` НЕ подгружаются автоматически (экономия контекста): открывай нужный раздел через grep/диапазон строк при обновлении статуса или при поиске названий. Словарь `docs/glossary.md`: единые названия персонажей, экранов, локаций, предметов и врагов; пользователь пользуется ими, новые названия сразу вноси туда. Кратко: ты координатор; классифицируй запрос и направляй агентам (таблица в rules.md); после любых изменений обновляй `status/checklist.md` и `status/context.md`; агенты после работы пишут README своей области. Технические правила проекта: `cursed-forest/CLAUDE.md`.
